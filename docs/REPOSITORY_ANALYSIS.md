# CATCH-AI: Repository Analysis

This document provides an analysis of the third-party repositories cloned for Phase 1 of CATCH-AI.

## 1. pytsk3_data-recovery
- **Purpose**: Python wrapper around The Sleuth Kit (TSK) for data recovery tasks.
- **Language**: Python
- **Key Modules**: Provides bindings to access disk images and file systems.

## 2. ForensicAI
- **Purpose**: Applies artificial intelligence to digital forensics, likely for artifact classification or anomaly detection.
- **Language**: Node.js / React
- **Key Capabilities**: AI-driven forensic analysis.

## 3. deep-recover
- **Purpose**: Utilizes deep learning techniques for data recovery or enhancement.
- **Language**: Python (expected)
- **Key Capabilities**: Neural network based recovery.

## 4. The Sleuth Kit (sleuthkit)
- **Purpose**: A comprehensive C/C++ library and set of command-line tools for analyzing disk images.
- **Language**: C/C++
- **Key Capabilities**: File system analysis (NTFS, FAT, ext, etc.), deleted file recovery.

## 5. libewf
- **Purpose**: A library for reading and writing the Expert Witness Compression Format (EWF).
- **Language**: C
- **Key Capabilities**: Handling EnCase image files (.e01).

## 6. Plaso (log2timeline)
- **Purpose**: A Python-based engine that extracts timestamps from various files and aggregates them into a timeline.
- **Language**: Python
- **Key Capabilities**: Timeline generation, parsing numerous forensic artifacts.

## 7. TestDisk
- **Purpose**: A powerful free data recovery software designed to help recover lost partitions and/or make non-booting disks bootable again.
- **Language**: C
- **Key Capabilities**: Partition recovery, boot sector repair.

## 8. compdec
- **Purpose**: A tool for compression and decompression.
- **Language**: Expected C/C++ or Python
- **Key Capabilities**: Handling compressed forensic data.
